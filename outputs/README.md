# Scored runs

These JSON files are the last **frozen-test** pictures, not training weights.

| File | What it is |
|------|------------|
| `RESULTS.md` | Comparison table generated by `./run.sh compare` |
| `base_eval.json` | Stock 0.5B, thin system prompt |
| `schema_eval.json` | Stock 0.5B, card schema in the prompt (no SFT) |
| `icl_eval.json` | Stock 0.5B, 8 train cards as few-shot (no SFT) |
| `adapter_eval.json` | 8-card LoRA, thin prompt |
| `curve/lora-{2,4,8,16}.json` | Same recipe, more or fewer labeled cards |

Diff `summary`, then read `per_prompt[].generation`.

Adapters (`outputs/lora-sft/`, `outputs/lora-sft-*/`) are gitignored. Produce them with `./run.sh train` or `./run.sh curve`, or download the [release](https://github.com/cobusgreyling/qwen-05b-min-sft/releases).
